# Media engine experiment

Standalone Windows prototypes; no production app linkage or release update. Run from
`C:\Work\openpilot`. The evidence cohort is `build/media_prototype/20261023`.

The same C++ host chooses IMFMediaEngine or dynamically loaded libmpv. Both render
through D3D11 into a 640×360 BGRA texture on a dedicated thread. Audio-only mode
skips D3D initialization entirely. Synthetic media, initially paused/muted playback,
owned windows and bounded process timeouts keep the experiment reversible.

## Reproduce

Dependencies are retained in the evidence cohort. `dependencies/PROVENANCE.json`
records the pinned release URLs and SHA256s. It contains libmpv from the shinchiro
20261021 build, its exact missing D3D11 header, and ffmpeg used only to make fixtures.
The fixture manifests retain encoder and lossless-remux commands and media hashes.
No codecs, DLLs or executables were installed globally.

From WSL:

```sh
python3 tools/media-prototype/build.py
```

From PowerShell 7, use a **new** evidence directory (prior runs are never replaced):

```powershell
pwsh.exe -NoProfile -File tools/media-prototype/compare.ps1 `
  -ResultDirectory C:\Work\openpilot\build\media_prototype\20261023\comparison-new
pwsh.exe -NoProfile -File tools/media-prototype/compare-video.ps1 `
  -ResultDirectory C:\Work\openpilot\build\media_prototype\20261023\video-comparison-new
```

`compare.ps1` checks the default multimedia audio endpoint before every run and at
completion, without changing its settings. Each run retains process exit/timeout,
raw engine telemetry/logs and parent-QPC timing. Frozen inputs are checked again at
completion. This is not a system-cold benchmark. No cache flushing or WSL shutdown.

To inspect either UI manually, launch the candidate explicitly:

```powershell
& .\build\media_prototype\20261023\candidate\media-prototype.exe `
  --file C:\Work\openpilot\build\media_prototype\20261023\fixtures\h264_aac.mp4 `
  --report C:\Work\openpilot\build\media_prototype\20261023\manual-mf-new.json `
  --visible --manual
```

Add `--mpv` for libmpv, or use `--audio-only` with an audio file. The automated
play/pause/seek checks run first, then the manual window remains open paused. Use
Play and Unmute to hear it; Close ends only this process. The helper is a prototype,
not a hardened arbitrary-media service. Report arguments should point at owned new
paths. Automated runs are muted; physical speaker audibility is not measured.

`SUMMARY.json`, `MEASUREMENTS.csv` and `MEASUREMENTS.md` are generated by
`python3 tools/media-prototype/summarize.py` from the two accepted retained matrices.
The script checks controls, stream presence, duration, dimensions, rendered frame
proof and expected rejections. It does not promote the interrupted first A/V run.
