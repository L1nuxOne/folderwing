# Folderwing

Folderwing is a native Windows file manager with optional WSL integration.

This repository is being prepared for the application source and automated builds.
The initial dependency release hosts the exact controlled PDFium GNU build and
LGPL-only media runtime, their build recipe or corresponding sources, and checksums.
Application releases will follow separately.

[Download the pinned build dependencies](https://github.com/L1nuxOne/folderwing/releases/tag/dependencies-20261025).
The release includes the matching media sources, PDFium build recipe and checksums.

Folderwing application code uses MIT. Dependency binaries retain their own licenses;
see the complete notices in each runtime archive. The media source archive belongs
with its matching media runtime. The PDFium recipe ZIP identifies immutable upstream
source revisions and portability changes; it is not a full PDFium source archive.

Planned homepage: https://l1nux.one/folderwing
